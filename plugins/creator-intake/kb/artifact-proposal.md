# Navrh Artefaktu

Pouzi tento tvar pri nejasnej alebo novej poziadavke.

```text
Odporucany artefakt:
Preco toto:
Preco nie alternativy:
Publikum a pristup:
Minimalne MVP:
Test:
Potrebne schvalenie pred zapisom:
```

Pri novom alebo upravovanom skille dopln aj:

```text
Skontrolovane existujuce skilly:
Najblizsi existujuci skill:
Preco neupravit existujuci:
Jedinecny trigger:
Jedinecny scope:
Jedinecne pravidla:
Odporucanie merge/split:
```

Pri MCP dopln aj:

```text
MCP server id:
MCP verejna URL:
Autentifikacny model:
Prvy read-only tool:
Bezpecnostny model zapisu:
No-fallback pravidlo:
Instalacia/login/novy chat test:
```

Pri feedbacku alebo navrhu pouzivatela dopln aj:

```text
Feedback target:
User-visible problem:
Likely artifact to change:
Do not edit source directly:
Privacy notes:
Suggested triage owner:
```

`Feedback target` je standardne:

```text
AI Agent/feedback/inbox/
```

Feedback proposal nesmie priamo menit `marketplaces/**`, Git repo ani ostre
skilly. Je to vstup pre admin triage.

Pri distribucii alebo update pre beznych pouzivatelov dopln aj:

```text
Git marketplace:
Codex marketplace ID:
Default plugins:
Install default plugins step:
Update step:
Needs new chat/refresh:
```
